家长化学速成指南 · 反应热与平衡篇

写给很久没碰化学的家长。目标不是让您会做题，而是：听得出孩子讲得对不对、问得出让她思考的问题。 阅读约 30 分钟。本期覆盖国庆专项第一主线：反应热（第一章）+ 速率与平衡（第二章）。 机动线若激活电化学，看文末"备用一页"。

一、30 分钟建立直觉（四个生活比喻，一次讲透半本书）

1. 反应热 = 记账（第一章核心）

化学反应就是"拆旧分子、建新分子"。拆键要花钱（吸热），建键能赚钱（放热）。一场反应下来账本上的差额，就是"反应热 ΔH"：赚钱多于花钱叫放热（ΔH 是负数），亏了叫吸热（正数）。

您只需问一句话："这个反应是赚是亏？亏多少跟什么数字对应？"孩子答得出"跟方程式里的计量数对应，计量数翻倍 ΔH 翻倍"，就过关。

2. 化学平衡 = 双向扶梯（第二章核心）

商场里的双向扶梯，一上一下同时有人走。上去的人数 = 下来的人数时，站在商场中庭的人看起来"不变"——但这不是没人走，而是两边一样快。可逆反应到了"平衡"，就是这个状态：正反应还在发生、逆反应也在发生，只是快慢相同。

追问一句："既然分子还在拼命反应，怎么叫'平衡'呢？"——孩子能答"表面对不上、里面全在动（动态平衡）"，说明真懂了。

3. 勒夏特列原理 = 弹簧（平衡移动）

平衡被外界打扰（升温/加压/加量）后，会往"削弱这个打扰"的方向偏移。像弹簧：你压它，它回弹一点，但回不到原来的长度——"减弱"而不是"抵消"。这句是考试里最阴的陷阱（会说成"恢复原状"来骗人）。

4. 反应速率 = 一屋子人撞保险箱

分子要撞开化学键，得"能量够高 + 位置够正"。升温 = 给更多人发钥匙；加浓度 = 往屋里塞更多人（比例没变）；加催化剂 = 给保险箱装电子锁（门槛降低，人人能开）。钥匙比例（活化分子百分数）和总人数（分子总数）是两回事——考试就在这两个词上挖坑。

二、三道"能讲给孩子听"的例题（不用算，只用问）

例 1（热化学）：为什么 1 mol S 的燃烧热和 2 mol S 的燃烧热说法不一样？

  • 您这样问："题目说'S 的燃烧热是 296 kJ/mol'，那 2 mol S 完全燃烧放热多少？为什么定义里非得说 1 mol？"
  • 听什么：2 mol 放 592 kJ；燃烧热定义钉死了"101 kPa、1 mol、完全燃烧、生成指定产物（SO₂）"，就像"单价"必须是 1 千克的价格，不能拿账单总额当单价。

例 2（平衡）：往可乐里加压，气泡为什么变多又变少？

  • 您这样问："打开冰可乐的一瞬间气泡狂冒，用今天的原理讲给我听。"
  • 听什么：开盖 = 压强骤减 → 溶解平衡被打破 → 二氧化碳"跑出去"的方向被促进（勒夏特列：向减弱压强减小的一侧移动）。能联系到"夏天更猛（温度升高气体更难溶）"更佳。

例 3（速率）：为什么妈妈炖肉用高压锅？

  • 您这样问："高压锅炖肉烂得快，用化学讲讲是哪两个因素在起作用？"
  • 听什么：温度高（活化分子百分数增大，主要）+ 压强大（浓度增大）。若她补一句"食堂把肉切小块是增大接触面积"，直接表扬——这是"外因四件套"之外的加分项。

三、批改作业时的"四问清单"（照着问，不用会做题）

  1. 状态呢？——热化学方程式里每个物质后面的 (g)/(l)/(s) 标了吗？ΔH 带符号和单位了吗？
  2. 基准呢？——这道题的 ΔH 是按"生成 1 mol 什么"算的？（水？还是别的？）
  3. 守恒查了吗？——方程式配平后，"得电子 = 失电子""原子种类数目不变"扫一眼了吗？
  4. 图像先看轴了吗？——横轴是温度还是时间？是"平衡线"还是"相同时间的快照"？

只挑这四类问题问，别问"对不对"——她自己会核对答案，您负责的是让过程慢下来。

四、常见雷区（您一句话就能戳破的）

孩子常说 您这样回
"这个反应要加热，所以是吸热的" "点鞭炮也要点火，鞭炮是吸热还是放热？"
"加了催化剂，产率提高了" "催化剂是加速器还是起重机？"（正确：只提速，不增产）
"压缩体积，浓度又变回去了" "弹簧被压了以后，回得到原长吗？"（正确：减弱≠抵消）
"平衡了就是反应停了" "扶梯上没人走了吗？"（正确：动态平衡）

五、备用一页：电化学（机动线激活才看）

  • 原电池 = 化学发动机：活泼金属当负极扔电子，电子顺导线跑，就有电流。口诀"负失氧、正得还"。
  • 电解池 = 充电泵：外接电源逼着反应发生。电镀 = 把金属"泵"到首饰上。
  • 防腐 = 替身演员：镀锌是给铁找替身挨刀（锌先被腐蚀）；外加电流是给铁"塞满电子"让它无从失起。

六、给您的三句话

  1. 您不需要懂化学，只需要会问上面那几个问题——问题对了，她自己会走到答案。
  2. 每天睡前 15 分钟的提问卡比陪做 2 小时题更值钱。
  3. 先夸行为再谈分数："今天这道题你把状态都标齐了"比"真聪明"有用得多。
