二、关键结论

  1. 选必一第一、二章是三校最大公约数：热化学三卷全考且分值稳定；速率与平衡两卷重头、一卷少量。无论申悦学校进度如何，《化学反应的热效应》+《化学反应速率与化学平衡》都是必考且权重最高的板块——这就是国庆专项的第一主线。
  2. 三校进度差异极大，第三章/第四章因校而异：
    • 华附：纯第一、二章（最贴近"9 月开学正常推进"的进度）；
    • 广大附中：已学到第三章（水溶液离子平衡），且考了分布系数、Kp 等较深内容；
    • 执信：已学到第四章（电化学），整卷约 60% 是电化学。
    • → 必须由申悦确认学校实际进度（问老师或看最近作业），决定国庆 Day4 机动线选哪条。
  3. 实验题是固定得分点，且高度集中在"量热"与"滴定"：中和热测定（华附选择 3 + 大题 17；执信选择 14A）、燃烧热测定/弹式量热计（华附大题 17 Ⅱ）、反应速率测定与控制变量（华附大题 18；执信选择 12）、氧化还原滴定（广大附中大题 17）。装置-操作-误差分析三件套必练。
  4. 图像题是第二章的灵魂：能量变化图/反应历程图（三卷都有）、转化率-温度图、选择性-温度图、浓度-时间图、速率-时间图。三卷合计图像类题目超过 10 道。
  5. 压轴题风格：化工生产情境（制钛/脱硝/合成甲醚/锂电回收/废电池回收），考"信息迁移 + 平衡常数计算 + 离子方程式"，不是偏题怪题，靠程序化步骤拿分。

三、修订后的月考范围假设（国庆专项依据）

第一主线 = 选必一《化学反应的热效应》+《化学反应速率与化学平衡》（三校最大公约数，真题证据充分）。 机动线（三选一，按学校进度）：电化学线（进度如执信）/ 水溶液线（进度如广大附中）/ 必修复习线（离子共存、方程式正误、元素化合物——若学校仍在铺必修）。
