一、热化学方程式组（选必一第一章）

# 反应 默写要点
1 H₂ 燃烧热：$\text{H}_2(\text{g}) + \dfrac{1}{2}\text{O}_2(\text{g}) = \text{H}_2\text{O}(\text{l})$，$\Delta H = -285.8\ \text{kJ/mol}$ H₂O 是 l；指定产物不是气态
2 C 燃烧热：$\text{C}(\text{s}) + \text{O}_2(\text{g}) = \text{CO}_2(\text{g})$，$\Delta H = -393.5\ \text{kJ/mol}$ 产物是 CO₂ 不是 CO
3 强酸强碱中和：$\text{H}^+(\text{aq}) + \text{OH}^-(\text{aq}) = \text{H}_2\text{O}(\text{l})$，$\Delta H = -57.3\ \text{kJ/mol}$ 以生成 1 mol 水为基准；弱酸弱碱不适用
4 铝热反应（示例）：$2\text{Al}(\text{s}) + \text{Fe}_2\text{O}_3(\text{s}) = \text{Al}_2\text{O}_3(\text{s}) + 2\text{Fe}(\text{s})$，$\Delta H < 0$ 全固体也要标 (s)
5 N₂ 与 H₂ 合成氨：$\text{N}_2(\text{g}) + 3\text{H}_2(\text{g}) \rightleftharpoons 2\text{NH}_3(\text{g})$，$\Delta H = -92.4\ \text{kJ/mol}$ 可逆号；工业情境题高频

二、速率与平衡情境方程式组（选必一第二章）

# 反应 默写要点
6 锌与硫酸：$\text{Zn} + 2\text{H}^+ = \text{Zn}^{2+} + \text{H}_2\uparrow$（离子方程式） 速率实验标配；加 Cu²⁻ 构成原电池加速
7 大理石与盐酸：$\text{CaCO}_3 + 2\text{H}^+ = \text{Ca}^{2+} + \text{H}_2\text{O} + \text{CO}_2\uparrow$ 块/粉影响接触面积
8 双氧水分解：$2\text{H}_2\text{O}_2 =(\text{MnO}_2)\ 2\text{H}_2\text{O} + \text{O}_2\uparrow$ 催化剂实验高频；条件写在等号上
9 NO₂ 二聚：$2\text{NO}_2(\text{g}) \rightleftharpoons \text{N}_2\text{O}_4(\text{g})$（$\Delta H<0$） 颜色变化/加压回调题的常客
10 氯水中平衡：$\text{Cl}_2 + \text{H}_2\text{O} \rightleftharpoons \text{H}^+ + \text{Cl}^- + \text{HClO}$ 光照变色题（HClO 分解）

三、必修复查组（离子共存 / 方程式正误题源）

# 反应 默写要点
11 钠与水：$2\text{Na} + 2\text{H}_2\text{O} = 2\text{NaOH} + \text{H}_2\uparrow$ 现象五件套：浮熔游响红
12 Na 与 O₂：常温 $4\text{Na}+\text{O}_2=2\text{Na}_2\text{O}$；点燃 $2\text{Na}+\text{O}_2=(\text{点燃})\ \text{Na}_2\text{O}_2$ 产物条件绑定，淡黄色火焰
13 Na₂O₂ 与 H₂O：$2\text{Na}_2\text{O}_2 + 2\text{H}_2\text{O} = 4\text{NaOH} + \text{O}_2\uparrow$ Na₂O₂ 中 O 为 −1 价（既升又降）
14 Na₂O₂ 与 CO₂：$2\text{Na}_2\text{O}_2 + 2\text{CO}_2 = 2\text{Na}_2\text{CO}_3 + \text{O}_2$ 供氧剂原理
15 碳酸氢钠受热：$2\text{NaHCO}_3 =(\Delta)\ \text{Na}_2\text{CO}_3 + \text{H}_2\text{O} + \text{CO}_2\uparrow$ 侯氏制碱链
16 Fe 与 Cl₂：$2\text{Fe} + 3\text{Cl}_2 =(\text{点燃})\ 2\text{FeCl}_3$ Cl₂ 氧化性强，只生成 +3 价
17 Fe 与盐酸：$\text{Fe} + 2\text{HCl} = \text{FeCl}_2 + \text{H}_2\uparrow$ 生成 +2 价（与 Cl₂ 对比记忆）
18 FeCl₂ 与 Cl₂：$2\text{Fe}^{2+} + \text{Cl}_2 = 2\text{Fe}^{3+} + 2\text{Cl}^-$ Fe²⁺/Fe³⁺ 转化的两条路（另一条加 Fe 粉：$2\text{Fe}^{3+}+\text{Fe}=3\text{Fe}^{2+}$）
19 铁的吸氧腐蚀（正极）：$\text{O}_2 + 2\text{H}_2\text{O} + 4e^- = 4\text{OH}^-$ 若学校学到电化学，本行升为必默
20 铜与浓硫酸：$\text{Cu} + 2\text{H}_2\text{SO}_4(\text{浓}) =(\Delta)\ \text{CuSO}_4 + \text{SO}_2\uparrow + 2\text{H}_2\text{O}$ 浓硫酸"酸+氧化"两重性

四、默写规则（每次都按这个标准）

  1. 状态必标：g / l / s / aq（热化学方程式）；离子方程式标 ↑↓。
  2. 条件写等号上：点燃/Δ/催化剂，括号小字。
  3. 可逆反应用 ⇌，不当普通箭头写。
  4. 电子守恒自查：氧化还原方程写完先查"得 = 失"再查原子守恒。
  5. 配平四查：原子、电荷、电子、奇偶（奇配偶法）。
