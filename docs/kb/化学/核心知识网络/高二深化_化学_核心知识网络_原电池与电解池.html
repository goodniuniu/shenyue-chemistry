核心内容

本卡为机动线卡片：三校中执信 10 月已考电化学，若申悦学校进度类似，本卡升为第一优先。

1. 原电池（自发，化学能→电能）

  • 判断口诀：负极——失电子、氧化反应、活泼金属（一般）；正极——得电子、还原反应。"负失氧，正得还"。
  • 电子流向：负极 →（导线）→ 正极；电流相反；电解质溶液中阳离子移向正极、阴离子移向负极（盐桥中同理：阳离子进正极室）。
  • 电极反应式书写三步：
    1. 写出电极上参加反应的物质与产物（看化合价变化）；
    2. 用电子配平电荷（酸性环境用 H⁺，碱性环境用 H₂O/OH⁻）；
    3. 用原子守恒配平 H、O。
  • 常考电池速记：铅蓄电池（放电 Pb + PbO₂ + 2H₂SO₄ = 2PbSO₄ + 2H₂O）、燃料电池（负极 = 燃料）、锌铜原电池、新型电池（读图提取信息："双极膜""质子交换膜"本质都是离子定向移动）。

2. 电解池（外接电源，电能→化学能）

  • 阴阳极判断看电源：阳极接正极（失电子、氧化），阴极接负极（得电子、还原）。
  • 放电顺序：
    • 阳极：活性电极（金属本身）> S²⁻ > I⁻ > Br⁻ > Cl⁻ > OH⁻ > 含氧酸根；
    • 阴极：Ag⁺ > Cu²⁺ > H⁺（酸）> … > Na⁺/Ca⁺ 等活泼金属离子（水溶液中不放电）。
  • 四大电解类型（电解质 / 结论）：
类型 例子 总反应 pH 变化
电解水 NaOH、H₂SO₄、Na₂SO₄ 溶液 2H₂O →(电解) 2H₂↑ + O₂↑ NaOH 增 / H₂SO₄ 减 / 盐不变
电解溶质 CuCl₂、HCl 溶质分解 视溶质
放 H₂ 生碱 NaCl 溶液 2NaCl + 2H₂O → H₂↑ + Cl₂↑ + 2NaOH 增大
放 O₂ 生酸 CuSO₄、AgNO₃ 溶液 2CuSO₄ + 2H₂O → 2Cu + O₂↑ + 2H₂SO₄ 减小
  • 精炼铜：粗铜作阳极、纯铜作阴极；电镀：镀层金属作阳极、待镀件作阴极，电镀液浓度不变。

3. 金属腐蚀与防护（执信卷连考 3 题）

  • 吸氧腐蚀（中性/弱酸性，最常见）：负极 Fe − 2e⁻ = Fe²⁺；正极 O₂ + 2H₂O + 4e⁻ = 4OH⁻。
  • 析氢腐蚀（较强酸性）：正极 2H⁺ + 2e⁻ = H₂↑。两种腐蚀的负极反应式相同（Fe 失电子）。
  • 防护三法：牺牲阳极（镀 Zn，比铁活泼的作负极被腐蚀）、外加电流阴极保护（被保护件接电源负极）、覆盖保护层。

4. 电化学计算万能钥匙——电子守恒

串联电路中通过各电极的电子数相同：$n(e^-)$ 相同。导出：析出金属质量比 = （摩尔质量 ÷ 化合价）之比。凡问"转移电子数/析出量/气体量"，一律先算 $n(e^-) = It/(96485\ \text{C/mol})$ 或按电极反应式比例。

🗣️ 费曼讲解（讲给零基础的人听）

原电池就是"化学发动机"：两个电极像两个脾气不同的人，活泼的那个（负极）总往外扔电子（花钱大方），扔掉的电子顺着导线跑到另一个电极（正极），被电解液里的阳离子捡走。导线里跑电子 = 电流，这就是电池。水果电池、手电筒，全是一回事。

电解池就是"充电泵"：跟原电池反着来，外接电源逼着电子往阴极灌，阴极附近的东西"被迫发财"（得电子被还原）。电镀就是把"金属涂层"泵到钥匙、项链上：要镀的东西当阴极，"涂料金属"当阳极慢慢溶解自己。

腐蚀防护就像替身演员：给铁找个更勇的替身（锌），让锌替铁挨刀（被氧化），铁完好无损——这就是镀锌铁皮划破后"锌烂铁不烂"。外加电流阴极保护则是给铁"塞满电子"让它根本没机会失电子——就像给钱包加锁，小偷无从下手。

📝 解题示范（一道典型题完整流程）

题：（执信 2025.10 卷 · 大题 19 改编）甲烷燃料电池（KOH 溶液）电解 Na₂SO₄ 溶液制 NaOH：写出 a 电极（通 CH₄）的电极反应式，并判断离子交换膜类型。原型见 真题试卷/ 执信卷第 19 题。

  1. 定电极：通 CH₄ 的一极 = 燃料 = 负极（碱性环境）。
  2. 写骨架：CH₄ → CO₃²⁻（碱性环境碳的归宿是 CO₃²⁻，不是 CO₂）。
  3. 配电子与电荷：左边 C 为 −4 价、右边 +4，失 8e⁻；产物侧 2 个 CO₃²⁻（碳守恒）带 4 个负电荷，左边加 10OH⁻ 配平电荷： $$\text{CH}_4 + 10\text{OH}^- - 8e^- = \text{CO}_3^{2-} + 7\text{H}_2\text{O}$$
  4. 查 H、O：左 H 14 个 O 10 个；右 H 14 个 O 10 个 ✓。
  5. 膜判断：产品室要得到 NaOH（Na⁺ 与 OH⁻ 相遇），Na⁺ 必须穿过膜 → 阳离子交换膜；阴极反应 2H₂O + 2e⁻ = H₂↑ + 2OH⁻。
  6. 检验：负极在碱性环境不能出现 H⁺；失电子写"−e⁻"在反应物一侧是否与习惯一致（电极反应式电子在左边为氧化）——此写法电子放左边并标负号，两种等价，考试以"反应物 − e⁻ = 产物"最稳。
