核心内容

1. 可逆反应与平衡状态

  • 可逆反应：同一条件下正逆同时进行。不能进行到底（这是三卷反复考的推理依据）。
  • 平衡标志（判断两问法）：
    1. 正逆相等问：$v_{正} = v_{逆}$（如"单位时间内断裂 X 键 = 生成 X 键"）；
    2. 变量不变问：某量原本随时间变化，后来不变（浓度、颜色、总压、平均摩尔质量、气体密度等——前提是这个量在反应中会变）。
    • 恒容容器中"气体总质量不变""密度不变"（全气相、恒容）不是标志；"混合气平均摩尔质量不变"对 $\Delta n \ne 0$ 的反应是标志，对 $\Delta n = 0$ 的反应不是。

2. 平衡常数 K

  • 表达式（以 $a\text{A}(\text{g}) + b\text{B}(\text{g}) \rightleftharpoons c\text{C}(\text{g}) + d\text{D}(\text{g})$ 为例）： $$K = \dfrac{c^c(\text{C}) \cdot c^d(\text{D})}{c^a(\text{A}) \cdot c^b(\text{B})}$$ 固体和纯液体不写入。
  • K 只随温度变：升温，若正反应吸热则 K 增大，放热则 K 减小。加压、加催化剂、改变投料，K 都不变。
  • K 的意义：K 越大，正向进行越彻底。$Q$（浓度商）与 K 比大小判方向：$Q < K$ 正向进行，$Q = K$ 平衡，$Q > K$ 逆向进行。
  • Kp（广大附中考过）：用平衡分压代替浓度，分压 = 总压 × 摩尔分数。写法同 K。

3. 转化率与三段式（计算题标准动作）

以三行式（起始 / 转化 / 平衡）列各物质 $n$ 或 $c$： $$\text{转化率} \alpha = \dfrac{n_{\text{转化}}}{n_{\text{起始}}} \times 100%$$ 恒温恒容时常用 $c = n/V$；"容器体积压缩一半"类问题用"浓度比较法"（压缩瞬间全体浓度×2，再与新平衡比，判断移动方向）。

4. 勒夏特列原理（平衡移动）

  • 原理：改变一个条件，平衡向减弱该改变的方向移动（注意是"减弱"不是"抵消"）。
  • 升温 → 向吸热方向动；加压 → 向气体分子数减小方向动；增大反应物浓度 → 正向动。
  • 催化剂不使平衡移动；恒容充惰性气体，各组分浓度不变，平衡不移动。
  • 注意"转化率联动"：增大一个反应物浓度，另一反应物转化率增大、它自己转化率减小（等效"分批加料"理解）。

5. 工业情境题答题套路（合成氨/制钛/脱硝）

为什么实际生产温度比理论高？→ 兼顾速率与催化剂活性（温度太低速率慢，催化剂需活性温度）；为什么用高压？→ 平衡正向移动提高转化率 + 速率增大，但要权衡设备成本。

🗣️ 费曼讲解（讲给零基础的人听）

化学平衡就像双向扶梯上的人流：上行（正反应）和下行（逆反应）同时进行，人数不变时不是没人走，而是"上去的和下来的一样多"——表面对不上，里面全在动。所以判断"到没到平衡"永远问两个问题：上去的是不是等于下来的（正逆相等）？还有什么东西在变吗（变量不再变）？

勒夏特列原理就是弹簧：你压它（加压），它就往小的方向缩（往气体少的那边动）；你加热它（升温），它就往吸热那边偏，把多出来的热"吃掉"一点。记住是"减弱你的改变"，不是"消灭你的改变"——压到 2 倍压，新平衡回不到原来的状态，只是"往回缩了一点"。

平衡常数 K 就像这场婚姻的"稳固指数"：只跟温度（媒人的热情程度）有关，跟你们怎么认识、谁先追谁（投料、浓度、压强）无关。改变温度以外的任何东西，K 纹丝不动——动的只是 Q 在追 K。

📝 解题示范（一道典型题完整流程）

题：（广大附中 2025.10 卷 · 大题 19 Ⅱ 改编）恒压 p₀，投入 CO₂ 2 mol、H₂ 6 mol 发生 $\text{CO}_2(\text{g}) + 3\text{H}_2(\text{g}) \rightleftharpoons \text{CH}_3\text{OCH}_3(\text{g}) + \text{H}_2\text{O}(\text{g})$，300 ℃ 平衡时 CO₂ 转化率 α，求 Kp。原型见 真题试卷/ 广大附中卷第 19 题。

  1. 三段式（设转化 $2\alpha$）：
CO₂ H₂ CH₃OCH₃ H₂O
起始/mol 2 6 0 0
转化/mol $2\alpha$ $6\alpha$ $2\alpha$ $2\alpha$
平衡/mol $2(1-\alpha)$ $6(1-\alpha)$ $2\alpha$ $2\alpha$
  1. 总数：$n_{总} = 8 - 2\alpha$。
  2. 分压：$p(\text{CO}_2) = \dfrac{2(1-\alpha)}{8-2\alpha}p_0$，其余同理。
  3. 代入：$K_p = \dfrac{\left[\dfrac{2\alpha}{8-2\alpha}p_0\right]^2}{\left[\dfrac{2(1-\alpha)}{8-2\alpha}p_0\right]\left[\dfrac{6(1-\alpha)}{8-2\alpha}p_0\right]^3} = \dfrac{\alpha^2(4-\alpha)^2}{27(1-\alpha)^4 p_0^2}$。
  4. 检验：①表达式中计量数 3 是否体现在 H₂ 的立方（幂次=计量数）；②固体/纯液体未出现（全气相，OK）；③单位：分压幂次差 $2-4=-2$，若要求写单位为 $p_0^{-2}$ 量级，检查是否漏了某物质的幂。
