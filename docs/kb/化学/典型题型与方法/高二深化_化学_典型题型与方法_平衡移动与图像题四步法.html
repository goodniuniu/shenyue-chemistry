核心内容

四步法（每道图像题都走这四步）

第一步：看轴。 横轴是什么（t / T / p / 浓度）？纵轴是什么（速率 / 转化率 / 物质的量分数 / 选择性 / 浓度）？先问"不反应时这条线应该长什么样"。

第二步：看起点与终点。 t=0 时有没有产物（决定起点从 0 还是从某值开始）；终态水平线 = 平衡（"不变"不等于"相等"）。

第三步：看拐点与突跃。 拐点 = 达平衡时刻；"先变深后变浅"类颜色突变 = 浓度瞬间被强行改变 + 平衡回调；虚线（平衡前）与实线（平衡线）分开画时，先判断虚线是"没到平衡"。

第四步：用规律收账。 把图像变化翻译成条件变化，用勒夏特列 + K 只随温度变解释。温度轴上的拐点对应 K 变化；压强/浓度轴上 K 不变。

高频图像类型速查表

图像类型 一眼要看出什么 易错点
能量-反应进程图 活化能（能垒）= 反应物到最高点；$\Delta H$ = 生成物与反应物能量差 催化剂只压低能垒，两端不动
转化率-温度图（催化） 先升后降：升段未平衡（速率控制），降段平衡线（放热反应升温降转化率） 顶点 ≠ 平衡点，是"相同时间"的最佳温度
选择性-温度图 多产物竞争路线：某产物选择性下降 → 该路线放/吸热推断 选择性 = 目标产物量 ÷ 总转化量
浓度-时间图 平台 = 平衡；突跃 = 外界条件改变 判断改变的是什么条件要看全部物质同帧变化
速率-时间图 v 正逆"剪刀差"后重合 = 新平衡 重合的高度未必回原位（加压两速率都抬高）
恒压充惰气 相当于减压 体积膨胀浓度全降

"等效+极限"技巧（判断不能进行到底）

可逆反应给"平衡时某物质几乎为 0"→ 只能说明转化率高，不能说明完全转化；判断" 最大限度"类问题用极限法：设完全反应算出极限值，实际值一定差一点点。

🗣️ 费曼讲解（讲给零基础的人听）

图像题就像看心电图。医生（你）要回答三个问题：心跳从什么时候开始稳了（拐点=平衡）？刚才那一抖是什么原因（条件突变）？现在的节律说明病人身体里发生了什么（用规律解释）。

四步法的关键是"先看轴再动笔"——很多同学上来就看线的形状猜答案，就像不看病历单就开始读心电图。横轴是温度还是时间，决定了这条线的"规则"完全不同：时间轴上"平台"是平衡；温度轴上根本不存在"平衡时刻"，每一个点都可能是平衡点。

为什么转化率-温度图会先升后降：低温区反应慢，给你的时间不够它跑到平衡（像比赛还没结束就拍照，成绩偏低）；温度升高跑得快，"相同时间成绩"上来了；到了高温区，虽然跑得更快，但这个反应本身放热、平衡后退（天花板降低了），成绩又开始掉。中间那个峰就是"速率 × 平衡"的最佳配合点——工业催化剂的最佳温度就是这么选的。

📝 解题示范（一道典型题完整流程）

题：（华附 2025.10 卷 · 选择 14 改编）密闭容器中足量固体与气体反应，甲、乙两种催化剂下相同时间测得转化率-温度图（先升后降两条曲线，甲峰在更高转化率）。判断活化能与 M 点状态。原型见 真题试卷/ 华附卷第 14 题。

  1. 看轴：横轴温度，纵轴"相同时间转化率"——注意不是平衡转化率（相同时间 = 拍快照）。
  2. 看拐点：曲线上升段 = 未平衡（速率控制）；下降段已接近平衡（热力学控制，该反应放热）。
  3. 比催化剂：相同温度下甲的转化率更高 = 甲跑得更快接近平衡 = 甲的活化能更低。
  4. 判 M 点：M 在上升段 → 未达平衡（选项若说"M 点达平衡"即错）。
  5. 检验：①有没有把"相同时间"偷看成"平衡"（本题最大陷阱）；②"催化剂不影响平衡"没错，但影响相同时间内达到的程度——两条曲线下降段应重合（同一平衡），若图中不重合说明下降段仍在趋近，说法留余地。
