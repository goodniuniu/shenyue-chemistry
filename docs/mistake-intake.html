考后错题入库速查（三步走）

月考一结束，错题就是最有价值的复习材料。照着这三步做，错题会变成知识库里的新卡片，AI 会自动分析失分板块、更新状态表、同步到网站。

第一步：拍照（考后当天，5 分钟）

  • 整卷拍照：每页一张，光线均匀、不歪斜（题目和选项都要清晰）
  • 答题卡/作答痕迹：孩子的原始作答过程一定要拍到——错在哪一步比错了哪道题更重要
  • 方程式特写：涉及方程式失分的题目，把她的原笔迹单独拍清楚（化学错题一半死在方程式细节：状态、配平、条件）
  • 标准答案：老师发答案后也拍一份（没有也行）

第二步：发给 AI（微信或直接对话）

发照片 + 一句话即可，任选：

  • "入库化学错题"
  • "这是申悦的月考试卷，请入库分析"
  • 错题少的话，只拍错题那几页也行

第三步：查看结果（约 10 分钟）

AI 会自动完成：

  1. 逐题归类到知识点（热化学 / 速率 / 平衡 / 电化学 / 必修复习……）
  2. 给典型错题建卡（四段式：核心内容 + 费曼讲解 + 解题示范 + 复盘要点）
  3. 化学特色：涉及方程式的错题，同步登记进方程式总表并打 ⚠️，进入滚动默写队列
  4. 更新《知识掌握状态表》的 ❌⚠️ 标记
  5. 更新网站和打印包
  6. 输出一份失分分析：哪个板块丢分多、是概念不清还是审题/计算失误、下一步怎么补
