# 申悦学习 · AI 指导化学学习

从国庆假期（2026.10.1–10.7）备战高二 10 月化学月考开始，用结构化知识库陪伴申悦到 2028 年高考的化学学习项目。

**运作模式**：每逢长假设计一期"专项复习计划"（诊断→主攻→模拟→复盘），平时用知识库做常态化碎片复习 + 早晚方程式默写。专项没用完的卡片和真题回流储备池，下期直接调用。

**主线依据**：2025.10 广州三校（华附/广大附中/执信）月考真题分析——反应热+速率与平衡是最大公约数，详见[真题分析报告](知识库/化学/素材与拓展/高二深化_化学_素材与拓展_广州三校高二上月考真题分析报告.md)。

## 网站内容（发布到 GitHub Pages）

- **首页**：项目导览与时间线
- **国庆 7 天辅导计划（v1）**：真题摸底 → 热化学/速率/平衡主线突破 → 机动线（默认电化学）→ 限时模拟与错题复盘
- **长假专项复习设计框架**：长假专项的通用设计模板，寒假专项将按此生成
- **家长化学速成指南 · 反应热与平衡篇**：写给很久没碰化学的家长（记账/扶梯/弹簧类比）
- **化学知识库**：概念卡 4 + 题型卡 2 + 陷阱卡 1 + 过关 30 问 + 方程式总表 + 真题分析 + 方法卡 2 + 状态表（常态化学习资源储备）
- **方程式总表**：化学的第二生命线，错题入库强制关联、早晚各 10 分钟滚动默写
- **卡片结构**：每张卡 = 核心内容（学）+ 费曼讲解（讲）+ 解题示范（练）+ 复盘要点（复盘），每页可一键打印

```

家长支持/长假专项复习设计框架.md      # 网站内容源：长假专项通用模板
家长支持/家长化学速成指南_反应热与平衡篇.md # 网站内容源：家长指南
知识库/                              # 网站内容源：全部知识卡片（Markdown，常态化资源储备）
知识库/化学/素材与拓展/真题试卷/      # 2025.10 广州三校月考真题原卷+解析 PDF
build_site.py                       # 构建脚本：Markdown -> docs/ 静态网站
build_print_pack.py                 # 打印包生成器：知识卡 -> 打印包/国庆打印包_化学.pdf
build_preview.py                    # 预览拼图生成器：打印包 PDF -> 打印包/预览_contact-sheet.png
打印包/                             # 打印包 PDF + 预览拼图
docs/                               # 生成的网站（GitHub Pages 发布此目录）
package.json                        # 本地预览：npm run dev
```

## 日常维护（每次更新内容只需三步）

1. 修改对应的 Markdown 文件（或直接让 AI 把错题"入库化学"）
2. 运行 `python build_site.py` 重新生成 `docs/`（打印包内容更新则再跑 `python build_print_pack.py`）
3. 提交并推送到 GitHub，网站自动更新

npm install   # 首次（本机已用目录联接复用物理项目的 node_modules，见 HANDOFF）
