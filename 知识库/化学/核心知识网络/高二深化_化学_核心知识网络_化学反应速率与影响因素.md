## 核心内容

### 1. 速率的表示与计算

- **定义式**：$v = \dfrac{\Delta c}{\Delta t}$，单位 mol/(L·s) 或 mol/(L·min)。**用物质浓度变化表示，不用固体和纯液体**。
- **换算关系**：同一反应中，各物质速率之比 = 化学计量数之比。如 $v(\text{N}_2) : v(\text{H}_2) : v(\text{NH}_3) = 1 : 3 : 2$，比较快慢先"归一"（都除以各自计量数）再比大小。
- **测定方法**：气体体积法（量气管/传感器）、比色法、电导法；碘钟（出现蓝色计时）。

### 2. 影响速率的因素（外因四件套）

| 因素 | 怎么变 | 微观解释（活化分子理论） |
|------|--------|------------------------|
| 浓度 | 增大反应物浓度 → 加快 | 单位体积内分子数增多，**有效碰撞次数增多**（活化分子**百分数不变**） |
| 压强 | 压缩体积（有气体）→ 加快 | 本质是浓度增大；恒容充惰性气体 → 速率**不变** |
| 温度 | 升温 → 加快 | 活化分子**百分数增大**（主要），碰撞频率也增 |
| 催化剂 | 加催化剂 → 加快 | **降低活化能**，活化分子百分数急剧增大，倍数关系最猛 |

### 3. 活化能与碰撞理论

- **活化能** $E_a$：活化分子的平均能量与反应物分子平均能量之差。**催化剂改变反应历程、降低活化能，但不改变 $\Delta H$、不改变平衡**。
- 有效碰撞 = 能量足够（≥ 活化能）+ 方向合适。
- 反应历程图：能垒（最高点）决定速率；决速步 = 能垒最高的那一步。

### 4. 控制变量实验设计（大题模板）

1. 找目的：探究某因素 X 对速率的影响；
2. 控变量：**只有 X 不同，其他全同**（温度、浓度、用量、催化剂种类用量）；
3. 补充试剂凑体积：如碘钟实验中加不同体积水/稀硫酸，使总体积一致；
4. 观测指标：相同时间比产量（气泡量/变色），或相同产量比时间（时间短 = 速率快）。
5. 答题语言：**"其他条件相同时，X 越大，反应速率越快，说明 X 对速率有影响"**。

## 🗣️ 费曼讲解（讲给零基础的人听）

**活化分子就像能开保险箱的人**：一屋子人（分子）都在乱撞（热运动），但只有口袋里钥匙够多（能量够高，活化分子）又恰好站对位置（取向合适）的人，才能把保险箱（化学键）撞开。升温 = 给全场的人发更多钥匙（活化分子百分数变大）；加浓度 = 往屋里塞更多人（人多了，撞开的次数自然多，但"带钥匙的比例"没变）；加催化剂 = 给保险箱装了个电子密码盘（降低了开箱门槛，钥匙少的人也能开）——**但保险箱里有多少钱（反应放多少热，$\Delta H$）一点没变**。

**控制变量就像公平比赛**：想知道"温度"对跑得快不快的影响，就必须让两个选手穿同样的鞋、走同样的路，只允许一个晒太阳一个吹空调。实验设计题里让你补加"水 X mL"，本质就是让两杯溶液总体积一样多——别让浓度偷偷变成第二个变量。

## 📝 解题示范（一道典型题完整流程）

> 题：（执信 2025.10 卷 · 选择 12 改编）探究锌与稀硫酸反应速率：Ⅰ组 2.0 g 锌粉 + 200 mL 0.2 mol/L 硫酸 25 ℃；Ⅱ组同量 35 ℃；Ⅲ组同量 25 ℃ + 0.1 g CuSO₄ 固体。判断哪组最快。原型见 `真题试卷/` 执信卷第 12 题。

1. **读表先找唯一变量**：Ⅰ vs Ⅱ 只差温度 → Ⅱ 快（升温加快）。
2. **Ⅲ 的隐藏变量**：加 CuSO₄，锌置换出铜，Zn-Cu 构成微小原电池（电化学催化）→ 比Ⅰ快。
3. **排序**：需比较 Ⅱ 与 Ⅲ 谁快——题给条件无法直接比较（35 ℃ 升温 vs 原电池加速，幅度未知），这类题若选项说"Ⅲ 一定最快"就是错的；能确定的是 Ⅱ > Ⅰ、Ⅲ > Ⅰ。
4. **检验**：回看是否漏了"控制变量"——三组锌量、硫酸体积浓度都相同，成立；结论只说"能确定的"，不过度推断。
